# Yuva-Intern_Week1
Performed data cleaning and exploratory analysis on the Titanic dataset using R. Handled missing values, detected outliers, encoded categorical variables, and analyzed numerical and categorical features using summary statistics, correlations, and visualizations to identify key patterns and insights.

###  Dataset

**Dataset:** Titanic Dataset
**Records:** 891
**Tools:** R, RStudio
**Libraries:** tidyverse, dplyr, ggplot2

###  Tasks Performed

* Loaded and inspected the dataset
* Checked dataset structure and summary statistics
* Identified and handled missing values
* Detected potential outliers
* Encoded categorical variables
* Performed data normalization
* Calculated descriptive statistics
* Analyzed correlations
* Created visualizations
* Explored survival patterns based on passenger characteristics

###  Key Insights

* Female passengers had a higher survival rate than male passengers.
* First-class passengers had a higher survival rate than second- and third-class passengers.
* Age contained missing values and required preprocessing.
* The analysis helped identify important patterns related to passenger survival.
